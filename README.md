# XLaunch

XLaunch 是一个面向 Windows 的轻量快速启动工具。它通过顶部横向分类栏和图标网格组织常用程序、文件与目录，目标是启动迅速、资源占用低、配置易编辑，并适合长期维护。

> 当前状态：真实启动项目与图标阶段。工程支持五类 Windows 启动目标、Shell 图标提取、DX11 纹理缓存、项目管理和本地 JSON 持久化。

## 项目边界

XLaunch 专注于分类、图标展示和本地启动项执行，不提供插件、文件索引、搜索引擎、AI、网络、云同步、账号或插件市场。

界面方向固定为：

- 顶部横向分类栏
- 主区域图标网格
- 简单直接的编辑体验

不会改为侧边栏、资源管理器布局或 Flow Launcher 风格的搜索框界面。

## 技术栈

- Visual Studio 2026
- C++20
- Win32 API
- Dear ImGui
- DirectX 11
- nlohmann/json

## 当前工程

根目录中的 `XLaunch.slnx` 和 `XLaunch.vcxproj` 是现有 Visual Studio 工程。当前支持 Win32/x64 的 Debug/Release 配置，使用 Unicode 字符集和 v145 工具集。

稳定的 Win32/DX11 生命周期仍保留在 `XLaunch.cpp`。数据模型、JSON 配置、Windows Shell 操作和主要编辑弹窗已按既定模块边界增量拆分到 `src/`，没有改变整体架构。

## 规划目录

```text
XLaunch/
├─ assets/                 # 应用自带的静态资源
├─ docs/                   # 架构、设计决策和维护文档
├─ src/
│  ├─ app/                 # 生命周期与模块编排
│  ├─ core/                # 数据模型和核心用例
│  ├─ config/              # JSON 读取、校验与保存
│  ├─ platform/            # Win32、Shell 和系统资源封装
│  ├─ renderer/            # DirectX 11 与 ImGui 后端
│  └─ ui/                  # 顶部分类栏、图标网格和编辑界面
├─ third_party/            # 经确认后引入的固定第三方依赖
├─ tests/                  # 纯逻辑模块的轻量测试
├─ AI_RULES.md
├─ README.md
└─ ROADMAP.md
```

目录按需创建，不建立无内容的占位层级。第三方依赖的引入方式和版本将在实现阶段单独确认。

## 构建状态

使用 Visual Studio 2026 打开 `XLaunch.slnx`，选择 `Debug | x64` 或 `Release | x64` 后构建运行。Dear ImGui v1.92.5 和 nlohmann/json v3.12.0 已固定在 `third_party/`，无需额外安装。

## 配置文件

配置保存在 `XLaunch.exe` 同目录的 `config\xlaunch.json`，自动备份位于 `config\backups\`，整个程序目录可直接移动作为绿色版使用。首次使用新路径时，如果发现旧的 `%LOCALAPPDATA%\XLaunch\xlaunch.json`，会安全复制到新目录以保留已有项目。保存时先完整写入 `xlaunch.json.tmp`，成功后再替换正式文件。

## 当前功能

- 顶部横向分类栏和自适应图标网格
- 新增、编辑、复制、移动和删除启动项目
- 普通启动、管理员启动和打开目标所在位置
- 分类新增、重命名和带项目迁移选项的删除
- 项目名称、边框、图标大小及网格间距设置
- 本地 JSON 配置自动保存和启动恢复
- exe、普通文件、文件夹、URL 和 lnk 五类项目
- Windows Shell 真实图标与 DX11 纹理缓存
- 单击启动以及右键管理员启动、编辑、删除和打开所在位置
- 从 Windows 资源管理器拖入单个或多个 exe、lnk、普通文件、文件夹和 url
- 空分类操作提示以及文件/文件夹原生浏览
- 紧凑型无系统边框界面，使用 Dear ImGui 原生窗口标题栏与边框
- 新增项目与设置保留在图标区域右键菜单，分类栏保留直接新增分类按钮
- 窗口位置支持屏幕四角、自定义坐标和每次呼出时的当前鼠标位置
- 全局鼠标中键或键盘组合键快速显示/隐藏窗口
- 紧凑双栏设置窗口；键盘快捷键支持 Ctrl、Alt、Shift、Win 与任意普通键录制
- 当前用户开机自启，无需管理员权限
- 配置手动导出、验证导入、立即备份及限量自动备份
- 默认关闭到系统托盘；托盘可显示/隐藏、打开作者主页或彻底退出
- 使用 `Xlaunch_ico.ico` 作为程序窗口、可执行文件和托盘图标
- 软件标题支持自定义及居中显示
- 鼠标快捷呼出支持中键/侧键、按住组合和双击手势
- 主窗口聚焦时可用 `Ctrl + 鼠标滚轮` 快速调整图标大小
- 单实例运行；再次启动 EXE 只唤醒已有窗口
- 固定模式使用真实 TopMost，适合从资源管理器拖入项目
- 48/64px 图标按目标尺寸从 Shell 图像列表或程序资源提取
- 隐藏到托盘后停止渲染并整理工作集
- 顶部“固定”按钮控制失焦/启动项目后是否自动隐藏；隐藏到托盘后停止连续渲染
- 项目图标和顶部分类标签支持拖动排序，顺序立即保存
- 标题显示当前版本 `v2026072801`，设置可调整整体窗口透明度
- 每个启动项可分别录制全局快捷键和仅主界面聚焦时生效的软件内快捷键
- 默认标题显示版本号；使用自定义软件标题时不追加版本号
- 全局 ImGui 按钮和输入控件使用低对比度细边框，避免与背景融为一体
- 可选“调整窗口后自动贴合网格”：左右边框贴合完整列，上下边框贴合最近的完整可见行，四角同时贴合列与行；未显示项目使用单一纵向滚动条
- 设置的“系统与备份”区域可直接打开绿色版 `config` 配置目录
- 位于 `XLaunch.exe` 目录内的目标、工作目录和自定义图标自动保存为相对路径，整个程序目录移动后仍可启动
- 响应 Windows `WM_DPICHANGED`，在不同缩放比例的显示器之间移动时动态调整窗口、ImGui 样式、字体与图标网格
- EXE 版本资源为 `v2026072801`，作者与版权所有者为 Mobius

图标优先使用用户指定的自定义图标；否则按项目类型从 exe、快捷方式、系统文件关联、文件夹或默认浏览器中提取。提取失败时使用统一系统备用图标。缓存按项目 ID、图标来源和显示尺寸失效，并在项目删除后释放无效纹理。

拖放使用 Windows OLE `IDropTarget` 和标准 `CF_HDROP`。拖入时图标区域显示当前目标分类；释放后立即解析并保存。lnk 保存解析后的真实目标、参数、工作目录和图标来源，url 文件保存其中的 URL。重复目标会先询问是否仍然添加。

## 开发方式

项目按小阶段推进。每一阶段先确认范围，再实现、编译和验证；不会一次性开发全部功能。
